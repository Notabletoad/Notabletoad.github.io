# Familienkalender

Eine kleine statische Website mit HTML, CSS und JavaScript. Das Projekt ist zugleich eine Sammlung von Web-Übungen und interaktiven Beispielen.

## Inhalte

- **Startseite (`index.html`)**: Familienkalender mit Beispielterminen, Einkaufsliste, Familiendaten und interaktiven Infofeldern.
- **Datum und Uhrzeit**: Die aktuelle Zeit wird auf der Startseite angezeigt und laufend aktualisiert.
- **Übungsseiten**: `Image.html` enthält ein kleines Quiz; `Button Übung.html` zeigt Beispiele für Buttons und Dropdown-Menüs.
- **Weitere Beispiele (`testordner/`)**: zusätzliche HTML-, CSS- und JavaScript-Übungen.
- **Gestaltung (`styles.css`)**: gemeinsame Formatierungen für die Seiten.

## Lokal starten

Du kannst die Dateien direkt im Browser öffnen. Alternativ lässt sich im Projektordner ein einfacher lokalen Webserver starten:

```bash
python -m http.server 8000
```

Öffne anschließend <http://localhost:8000> im Browser.

## Technologien

- HTML
- CSS
- JavaScript

Es werden keine Abhängigkeiten oder Build-Schritte benötigt. Die Inhalte und Termine sind Beispiele, die direkt in den HTML-Dateien gepflegt werden; das Projekt verwendet derzeit kein Backend oder eine gemeinsame Online-Datenspeicherung.
